# filekat

The official KAUI CSS Kit package for Web, React, Next.js, Vite, and other modern Web applications.

## Installation

```bash
npm install filekat
```

## Quick Start

Import the package root. It includes the production KAUI CSS bundle and icon styles:

```tsx
// Next.js app/layout.tsx, React, or Vite entrypoint
import 'filekat/kaui';
```

For the expanded development stylesheet:

```tsx
import 'filekat/css';
```

For optional charts:

```tsx
import 'filekat/charts';
```
