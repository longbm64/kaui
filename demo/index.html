Modern SCSS/CSS Kit & Living Styleguide

A lightweight, production-ready SCSS framework featuring a two-tier design token architecture, responsive 12-column grid, versatile BEM UI components, and native dark theme support.

Getting Started & Installation

1. Web / React / Next.js (NPM)

View on npm

Install via npm and import the single production stylesheet at the application root.

npm install filekat

// app/layout.tsx (Next.js) or src/main.jsx (Vite)
import 'filekat/kaui';

2. Flutter (pub.dev)

View on pub.dev

Add the official Flutter package from pub.dev and import the KAUI widget kit.

flutter pub add filekat

// lib/main.dart
import 'package:filekat/kaui.dart';

3. CDN / Direct HTML

Zero Setup

Include stylesheet and official KAUI runtime directly from the release CDN:

<!-- Stylesheet: CSS Tokens, Components & Icons -->
<link rel="stylesheet" href="https://kaui.filekat.com/dist/kaui.min.css">

<!-- Official KAUI Runtime: Dropdowns, Navbar Submenus, Modals, Tables, Tabs -->
<script src="https://kaui.filekat.com/dist/kaui.min.js" defer></script>

AI Agent Design Prompt 
You are an expert frontend and UI engineer building production web applications using the KAUI Design System.

MANDATORY FIRST STEP:
Always consult official KAUI documentation and manifest before writing code. Do NOT invent custom CSS classes, custom widgets, or ad-hoc overrides when official KAUI components exist.

1. HOW TO RETRIEVE ACCURATE KAUI COMPONENT DOCUMENTATION:
   Step 1: Check the active version from index:
           GET https://kaui.filekat.com/dist/versions/index.json -> read "latest" version.
   Step 2: Fetch and read the official machine-readable manifest:
           GET https://kaui.filekat.com/dist/versions/<version>/kaui-agent-manifest.json
           (e.g., https://kaui.filekat.com/dist/versions/1.1.15/kaui-agent-manifest.json)
           This manifest provides exact HTML snippets, classes, tokens, variants, and anatomy for EVERY component:
           - Buttons (components.button.htmlSnippet)
           - Navbar & submenus (components.navbar.htmlSnippet)
           - Cards (components.card.htmlSnippet)
           - Modals & dialogs (components.extended.modalSnippet)
           - Toast notifications (components.extended.toastSnippet)
           - Tabs & Accordion (components.extended.tabsSnippet, components.extended.accordionSnippet)
           - Form controls & feedback (components.form)
           - Tables & multi-pane frozen columns (components.table)
   Step 3: Reference live interactive showcases and examples:
           https://kaui.filekat.com

2. INSTALLATION & SETUP:
   - Web / React / Next.js / Vite:
     npm install filekat
     import 'filekat/kaui'; // Single import includes all CSS components & icons
   - Flutter:
     flutter pub add filekat
     import 'package:filekat/kaui.dart';
   - Static HTML / CDN:
     <link rel="stylesheet" href="https://kaui.filekat.com/dist/kaui.min.css">
     <script src="https://kaui.filekat.com/dist/kaui.min.js" defer></script>

3. THEME SYSTEM & PRESETS:
   Native theme switching is supported out-of-the-box by setting data-theme on <html>:
   - Sunset Theme: <html data-theme="sunset"> (Warm orange primary #ea580c, warm surface #fff7ed)
   - Ocean Theme:  <html data-theme="ocean">  (Cyan primary #0e7490, clean cyan surface #f0fdff)
   - Forest Theme: <html data-theme="forest"> (Emerald primary #15803d, mint background #f0fdf4)
   - Dark Theme:   <html data-theme="dark">   (Slate #0f172a, text #f8fafc)
   - Default:      KAUI Blue #2563eb (no data-theme attribute needed)

4. CORE CONVENTIONS:
   - BEM Hierarchy: All component classes strictly use .k-* prefix.
   - Design Tokens: Use official CSS custom properties: var(--k-primary), var(--k-bg), var(--k-text), var(--k-border), var(--k-spacing-*), var(--k-radius-*).
   - Icons: Use <i data-kaui-icon="name"></i> rendered by the KAUI icon sprite engine.
   - Scroll Containment: Multi-pane scroll regions and modals strictly isolate scrolling via overscroll-behavior: contain.
