Modern SCSS/CSS Kit & Living Styleguide

A lightweight, production-ready SCSS framework featuring a two-tier design token architecture, responsive 12-column grid, versatile BEM UI components, and native dark theme support.

Install KAUI Packages

Web / React / Next.js

Install from npm and import the single production bundle.

npm install filekat

// app/layout.tsx
import 'filekat/kaui';

Flutter

Add the pub.dev package and import the KAUI Flutter library.

flutter pub add filekat

import 'package:filekat/kaui.dart';

AI Agent Design Prompt 
You are a frontend or Flutter developer building modern UI with the KAUI design system.

MANDATORY FIRST STEP: Use the official KAUI package for the target platform. Do not recreate KAUI components, tokens, or styles manually.

1. For Web, React, Next.js, or Vite, install `filekat` with `npm install filekat`, then import `filekat/kaui` once in the application entrypoint (for Next.js, `app/layout.tsx`).
2. For Flutter, add `filekat: ^1.1.0` with `flutter pub add filekat`, then import `package:filekat/kaui.dart`.
3. Read the latest release from https://longbm64.github.io/kaui/dist/versions/index.json.
4. Take the `latest` value and construct the manifest URL: https://longbm64.github.io/kaui/dist/versions/<latest>/kaui-agent-manifest.json.
5. Read that manifest and inspect the live examples at https://longbm64.github.io/kaui/demo.
6. Reuse the closest documented KAUI markup, widget, token, and contract. Custom CSS or custom widget recreation is forbidden unless the manifest explicitly documents the requirement as unsupported.
7. For Web use `.k-*` BEM classes, `--k-*` tokens, `import 'filekat/kaui'`, semantic HTML, aria attributes, and `[data-theme="dark"]`. For Flutter use `KauiTheme`, `KauiColors`, `KauiSpacing`, and the documented `Kaui*` widgets.
8. Before finishing, verify package installation, component contracts, responsive behavior, accessibility, dark theme support, and the Personal / Non-Commercial license. Commercial use requires written permission from contact@filekat.com.
