Usage guide & code sample

Use .k-container with .k-grid and 12-column span classes. Combine breakpoints like .k-col-12.k-col-md-6 for responsive flow.

<div class="k-grid k-gap-4">
  <div class="k-col-12 k-col-md-6">Left column</div>
  <div class="k-col-12 k-col-md-6">Right column</div>
</div>
