Usage guide & code sample

Compose cards from header, title, body, and footer regions. Add .k-card--bordered for a defined surface.

<article class="k-card k-card--bordered">
  <div class="k-card__header">Account</div>
  <div class="k-card__body">Plan details</div>
  <div class="k-card__footer">Updated today</div>
</article>
