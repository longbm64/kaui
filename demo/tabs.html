Usage guide & code sample

Pair each tab with a panel using data-tab-target. Mark the initial tab and panel with is-active and expose tab semantics with ARIA roles.

<div class="k-tabs__list" role="tablist">
  <button class="k-tabs__tab is-active" data-tab-target="#profile" role="tab" aria-selected="true">Profile</button>
</div>
<div id="profile" class="k-tabs__panel is-active" role="tabpanel">Profile content</div>
