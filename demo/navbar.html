Navigation Bar (.k-navbar)

Responsive header bar with brand, collapsible links drawer, and responsive actions.

KAUI App
  • Tokens
    • Buttons
      • Tables
      • Charts
  • Icons

Usage guide & code sample

Use .k-navbar with optional modifiers for sticky, shadow, transparent, dark, compact, centered, and borderless surfaces. Add .k-navbar__actions for CTAs and .k-navbar__submenu for nested navigation.

<header class="k-navbar k-navbar--sticky k-navbar--shadow">
  <div class="k-navbar__container">
    <a href="#" class="k-navbar__brand">Brand</a>
    <nav class="k-navbar__menu">
      <ul class="k-navbar__nav">
        <li><a href="#" class="k-navbar__link is-active">Home</a></li>
        <li class="k-navbar__item--has-children">
          <a href="#" class="k-navbar__link">Products</a>
          <ul class="k-navbar__submenu"><li><a href="#" class="k-navbar__link">Overview</a></li></ul>
        </li>
      </ul>
      <div class="k-navbar__actions"><button class="k-btn k-btn--primary">Get started</button></div>
    </nav>
  </div>
</header>
