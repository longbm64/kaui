Modal Component (.k-modal)

Accessible static-by-default dialog with backdrop, structured header/body/footer, and opt-in click-outside dismissal.

Usage guide & code sample

Add is-open to the modal container and data-k-backdrop="static" to keep it static (the default). Use data-k-backdrop="true" only when click-outside dismissal is required.

<div class="k-modal is-open" role="dialog" aria-modal="true" data-k-backdrop="static">
  <div class="k-modal-backdrop"></div>
  <div class="k-modal__dialog">
    <div class="k-modal__header"><h3 class="k-modal__title">Title</h3></div>
    <div class="k-modal__body">Dialog body text</div>
    <div class="k-modal__footer"><button type="button" class="k-btn k-btn--primary">Confirm</button></div>
  </div>
</div>
