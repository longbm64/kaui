Code Area .k-code-area

A clean container for code blocks with top-right one-click copy button, visual feedback (Copied checkmark), custom syntax headers, and native dark mode support.

1. Standard Code Area (with auto-generated Copy button)

Just wrap your code inside .k-code-area with .k-code-area__pre. The top-right Copy button is automatically wired.

// JavaScript Example: Fetching user details
async function fetchUserProfile(userId) {
  const res = await fetch();
  if (!res.ok) throw new Error('Failed to load user profile');
  const user = await res.json();
  return user;
}

2. Code Area with Header & Language Title

Include .k-code-area__header with a title or language badge.

Usage guide & code sample

Use the HTML below to embed code blocks in your applications:

<div class="k-code-area">
  <pre class="k-code-area__pre"><code>console.log('Hello KAUI!');</code></pre>
</div>
