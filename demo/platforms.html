Platform Packages & Developer Workflow

KAUI tokens and contracts are prepared for Web/Next.js, Flutter, Android Compose, and iOS SwiftUI.

Web / Next.js

Import the single CSS bundle globally.

kaui

Flutter

Use KauiTheme and core native widgets.

kaui

Android Compose

Generate Compose tokens from the registry.

com.kaui

iOS SwiftUI

Use KauiTokens with SwiftUI views.

KaUI

Design Tokens

One JSON source generates platform-ready token outputs.

npm run tokens:build
npm run tokens:verify

Source: tokens/kaui.tokens.json
Output: dist/tokens/

KAUI Icons

Proprietary 24x24 SVG icons using currentColor and a shared sprite.

npm run icons:build

Source: icons/source/
Output: dist/icons/

Verify artifacts, licenses, manifests, tokens, and icon outputs before publishing a release.
