Installation

Add KAUI to a static page

Install the package from npm, then reference the generated stylesheet in your HTML. Replace the sample markup with your application layout.

<!-- 1. Install via npm -->
npm install filekat

<!-- 2. Reference CSS in your HTML -->
<link rel="stylesheet" href="node_modules/filekat/dist/kaui.min.css">
<link rel="stylesheet" href="node_modules/filekat/dist/icons/kaui-icons.css">

<!-- 3. Use KAUI components -->
<div class="k-container">
  <button type="button" class="k-btn k-btn--primary">Get started</button>
</div>
